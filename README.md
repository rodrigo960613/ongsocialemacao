# 💙 ONG Social em Ação

Landing page institucional desenvolvida para a **ONG Social em Ação**, com o objetivo de apresentar a organização, seus serviços, formas de contato e canais de apoio à comunidade.

O projeto foi desenvolvido com foco em uma interface moderna, acessível, responsiva e alinhada à identidade visual da organização.

## 📌 Sobre o projeto

A **ONG Social em Ação** atua oferecendo serviços e apoio à comunidade em diferentes áreas, como saúde, documentação, assistência social, educação, esporte, empregabilidade e infraestrutura.

O site foi criado para facilitar o acesso às informações da ONG e aproximar a organização das pessoas que precisam de seus serviços.

## 🚀 Funcionalidades

* Página inicial com apresentação da ONG
* Seção "Sobre Nós"
* Apresentação dos principais serviços oferecidos
* Seção de doação
* Botões de contato via WhatsApp
* Links para Instagram e Facebook
* Localização da ONG integrada ao Google Maps
* Horário de atendimento
* Footer institucional
* Navegação por âncoras entre as seções
* Design responsivo para diferentes tamanhos de tela
* Efeitos de hover e transições nos elementos interativos

## 🛠️ Tecnologias utilizadas

* **React**
* **JavaScript**
* **Vite**
* **HTML5**
* **CSS3**
* **SVG** para os ícones
* **Google Maps** para localização
* **WhatsApp** para contato

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/ong-social-em-acao.git
```

### 2. Entre na pasta

```bash
cd ong-social-em-acao
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Depois, acesse o endereço informado pelo Vite, normalmente:

```text
http://localhost:5173/
```
